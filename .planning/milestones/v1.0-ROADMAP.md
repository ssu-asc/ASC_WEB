# ASC 2026-2 Core Operations Portal — v1.0 Roadmap Archive

Shipped: 2026-09-17
Audit: `.planning/v1.0-MILESTONE-AUDIT.md` — PASSED

## Milestone outcome

v1.0 turns the existing static ASC website into a production Member operations portal while preserving the public-site design. Supabase Auth/Postgres/Edge Functions provide the operational system of record, the existing `ssu-asc/ProjectDB` remains the Markdown report system of record, and no new paid storage/VPS/document platform is required.

## Completed phases

### Phase 1 — Member Portal Tracer
Issued ASC accounts, database-backed profiles/semester membership, login, real status reads, and fail-closed configuration states.

### Phase 2 — Git Project Submissions
Initial individual/team submission model and ProjectDB verification boundary, later evolved by Phase 10 into Markdown upload + automatic publication.

### Phase 3 — Staff Review
Roster-derived expected/missing/submitted/revision/approved state and durable staff review workflow.

### Phase 4 — Semester Schedule
Member-facing general events and project timing in one schedule surface.

### Phase 5 — Operations Redesign
Semester-fixed teams, scheduled project rounds with `opens_at`/`due_at`, alternating round materialization, late semantics based on first submission, action-first member dashboard, and round-first staff overview.
